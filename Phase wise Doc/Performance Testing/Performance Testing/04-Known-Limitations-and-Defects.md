# Known Limitations and Defects

Items visible in the README/source snapshot; verify current behaviour before submission.

1. **Demo payments only:** no real payment gateway is connected.
2. **No real refund processing:** refund amounts/statuses are demonstration records only.
3. **No email/SMS or QR tickets:** confirmations are handled in the web app.
4. **Show deletion:** admin API supports listing, creating and updating shows; no show-delete route is present in the inspected route files.
5. **Show window:** customer show listings are described as limited to a future seven-day window in the project README; verify current service configuration.
6. **Performance data:** no measured performance results were supplied.
7. **Deployment variability:** free-tier hosting, cold starts and network conditions may affect observed response times.
