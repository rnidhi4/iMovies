# Customer Journey Map

## Moviegoer journey
1. Open iMovies.
2. Browse current/upcoming movies and filters.
3. Open a movie and review description and showtimes.
4. Choose a show and inspect seat availability.
5. Sign in/register if required.
6. Select seats and request a temporary hold.
7. Complete simulated payment.
8. Review booking confirmation and reference.
9. Open My Bookings to view past/upcoming/cancelled records.
10. Cancel an eligible booking if needed.

## Admin journey
1. Sign in with an account assigned the admin role.
2. Open the admin dashboard.
3. Review statistics and registered users.
4. Manage movies, theatres and screens.
5. Create/update shows and change active status.
6. Search/filter bookings and cancel a booking when appropriate.

## Potential friction points
- Seat hold can expire during checkout.
- Demo payment is not a real payment.
- A user may need to sign in before completing a booking.
- Network errors can prevent API data from loading.
