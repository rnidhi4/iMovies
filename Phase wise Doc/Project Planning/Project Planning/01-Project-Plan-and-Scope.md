# Project Plan and Scope

## Project
**iMovies — Movie Ticket Booking System**

## Objective
Build a full-stack web application where customers can discover movies and showtimes, select seats, create a booking, complete a simulated payment, and manage their bookings. Administrators can manage the movie catalogue, theatres, screens, showtimes, bookings, and users.

## Scope included in the supplied code
- User registration, login, logout and current-user lookup.
- Movie listing, movie details and movie showtimes.
- Theatre listing and show seat-layout retrieval.
- Temporary seat holds and expiry handling.
- Demo payment success/failure workflow.
- Booking history, details and eligible cancellation.
- Admin catalogue, showtime, booking and user management.

## Out of scope / not represented as live services
- Real payment processing.
- Real refunds through a bank or payment gateway.
- Email/SMS notifications and QR-code ticket delivery.
- Claims of production-grade load capacity without measured tests.

## Deliverables
1. React/Vite frontend.
2. Node.js/Express REST API.
3. MongoDB/Mongoose data models.
4. Authentication and role-based admin access.
5. Booking and demo-payment workflow.
6. Phase-wise documentation and full-stack project report.

## Tools and technology
React, Vite, JavaScript, Bootstrap, React Router, Axios, Node.js, Express, MongoDB, Mongoose, Git, GitHub and VS Code.
