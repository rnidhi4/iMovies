# Empathy Map (Assumed Personas)

These are design assumptions for a student project, not results from user interviews or a formal survey.

## Persona A: Moviegoer
- **Says:** “I want to see which movies and showtimes are available.”
- **Thinks:** “Are the seats still available? Is my booking confirmed?”
- **Does:** Browses movies, opens a show, selects seats, completes demo payment and checks My Bookings.
- **Feels:** Wants the process to be clear and predictable.
- **Needs:** Clear showtime details, seat status, booking reference and cancellation information.

## Persona B: Administrator
- **Says:** “I need to update movies and show schedules.”
- **Thinks:** “I need to see booking activity and manage records safely.”
- **Does:** Maintains movies, theatres, screens and shows; reviews bookings and users.
- **Feels:** Needs reliable and understandable admin tools.
- **Needs:** Role-protected access, validated forms, searchable booking records and useful status indicators.
