# Problem Statement

## Background
Moviegoers need a convenient way to find films, check showtimes, view seat availability and organise ticket bookings. A manual or fragmented process can require users to check different sources and can make booking status difficult to track.

## Problem
A single place is needed to browse a movie catalogue, inspect available shows, choose seats and keep a record of bookings. Administrators also need a structured interface to maintain movies, theatres, screens and showtimes.

## Proposed idea
iMovies is a web-based movie ticket booking demonstration built with the MERN stack. It provides movie discovery, seat selection, a temporary seat-hold workflow, simulated payment and booking management. An admin area supports catalogue and show management.

## Objectives
- Provide a clear movie and showtime browsing experience.
- Prevent the same seat from being allocated to multiple active bookings.
- Let users review booking status and cancel when eligible.
- Give administrators tools to manage catalogue and operational data.
- Demonstrate frontend/backend/database integration.

## Scope boundaries
The application simulates payment. It does not claim to process real financial transactions or issue real payment refunds.
